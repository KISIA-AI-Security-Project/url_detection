# L4 검증과 독립 검토 기록

검토 기준은 [AGENTS_SDK.md](AGENTS_SDK.md)에 연결된 세 설계·구현 문서와 사용자의 후속 합의다. 구현 작업이 수정 책임을 유지하고 독립 검토자는 고정 사본과 같은 입력·결과를 읽는다.

| 자료 | 범위 |
|---|---|
| [페이지 조회 통합 검증](../output/l4-page-query-consolidation-20261002/verification.md) | 18개 공개 Tool, 선택 조회·상태 일치·SDK 전달, 이번 관련 회귀와 독립 검사 |
| [SDK 구현 검증](../output/l4-sdk-implementation-20261002/verification.md) | SDK 실행·Store·파일 연결과 마지막 총괄 판단 검증 |

브라우저·Bash·파일 검사는 실제 로컬 실행을 사용한다. 모델 응답은 통제된 SDK Model이고 AWS는 메모리 대역이다. 이전 Store의 실제 AWS 저장 검증과 새 SDK의 전체 운영 경로 검증은 구분한다. 테스트 통과는 조사 판단 품질이나 전체 서비스 완료를 뜻하지 않는다.

SDK 정리 당시의 전체 회귀는 **484개 통과**였다. 당시 독립 검토자는 고정 사본에서 SDK 관련 **46개 통과**를 재현하고, 이관 외 native 검사 212개 함수가 유지된 것을 확인했다. 그때 연결 문서에서 찾은 구버전 등록 예시는 SDK 방식으로 수정했다. 해당 범위와 확인 자료는 위 정리 검증 문서에 보존한다.

그 후 페이지 조회 통합에서는 기존 관련 검사 124개와 새 통합 검사 8개가 통과했다. 독립 검토는 새 8개와 다중 탭 SDK 1개를 실행하고 같은 입력·반환을 대조했다. 이는 이번 변경의 검증 범위이며 이전 전체 484개를 다시 실행한 결과가 아니다.
